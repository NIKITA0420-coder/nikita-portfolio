# Nikita T — Portfolio

🔗 **Live site:** [nikita-6178-portfolio.netlify.app](https://nikita-6178-portfolio.netlify.app)

A single-page personal portfolio for **Nikita T**, a final-year Electronics & Communication Engineering student working across embedded systems and AI/LLM-powered software. The site highlights skills, projects, internships, patents, education, and certifications, with a clean, animated, dark/light-mode-ready design.

## ✨ Features

- **Light/Dark theme toggle** with persisted preference
- **Animated hero section** with a typing effect for role titles
- **Scroll progress bar** and smooth in-page navigation
- **Responsive layout** optimized for mobile and desktop
- **Project filtering** (All / AI / Hardware)
- **Contact modal** with quick "compose email" and copy-to-clipboard actions
- Sections: About, Skills, Projects, Experience, Achievements/Patents, Education, Certifications, Contact

## 🧑‍💻 About Nikita

Final-year B.E. Electronics & Communication Engineering student (V.S.B College of Engineering Technical Campus, 2023–2027) who moves comfortably between microcontroller firmware and backend APIs — with a growing focus on **AI and LLM-powered projects**.

- 🎓 CGPA: 8.85
- 📄 2 patents filed
- 💼 3 internships completed
- 📍 Coimbatore, Tamil Nadu

## 🛠️ Tech & Tools Featured

**Languages / Frameworks:** Java, SQL, HTML, CSS, JavaScript, FastAPI
**Hardware:** ESP32, Arduino
**AI:** Groq Cloud API / LLM (Llama 3.3 70B)

## 📂 Highlighted Projects

| Project | Type | Stack |
|---|---|---|
| **Sentinel — Sentiment & Urgency Detector** | AI-Powered | FastAPI, Python, Groq (Llama 3.3), SQLite, JavaScript |
| **Fire Fighting Robot using ESP32** | Hardware | ESP32, L298N, Flame Sensors, LM2596, Li-ion Battery |

## 🚀 Tech Stack (this site)

- Plain **HTML5 / CSS3 / JavaScript** (no build step, no frameworks)
- Google Fonts: **Manrope** & **Inter**
- Deployed on **Netlify**

## 📦 Getting Started Locally

1. Clone or download this repository.
2. Open `index.html` directly in your browser — no build tools or dependencies required.

```bash
git clone <repo-url>
cd <repo-folder>
open index.html   # or just double-click the file
```

## 🌐 Deployment

This site is deployed on **Netlify**:
👉 https://nikita-6178-portfolio.netlify.app

To deploy your own copy:
1. Push this repo to GitHub.
2. Connect the repo to Netlify.
3. Set the publish directory to the project root (contains `index.html`).
4. Deploy 🚀
